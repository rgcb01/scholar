# Scholar

Scholar is an experimental Minecraft mod project in pre-development. The name is a working name and may change before any public release.

The long-term goal is to build scientific and educational document infrastructure for Minecraft: structured documents that can be rendered, edited, exchanged, and extended by other mods. Scholar is intended to be reusable infrastructure, not a single lesson pack or a complete STEM platform by itself.

Scholar is part of a broader long-term STEM vision for Minecraft. The document engine and any future physics or STEM laboratory systems are separate projects with separate responsibilities.

Current target platform:

- Minecraft Java Edition `1.21.1`
- NeoForge `21.1.x`
- Java `21`
- Gradle wrapper `9.2.1`

No claims are currently being made about improving learning outcomes. The project is still establishing its foundation, scope, and architecture.

## Development

Build the project with:

```bat
.\gradlew.bat build
```

The mod id is currently `scholar`, and the base Java package is `dev.rgcb.scholar`.
